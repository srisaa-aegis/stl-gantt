# Changelog

## 0.1.0

First public release.

- Gantt chart: outline, drag to move / resize / set progress, add, delete, indent, outdent, reorder
- Dependencies FS, SS, FF, SF with lag or lead; loop and duplicate checks
- Working calendar with weekly days off and holidays
- Scheduler that pushes linked tasks later, never earlier
- Critical path and total slack
- Day / week / month / quarter zoom, today line, deadline diamonds, read-only mode
- Pure core usable without the DOM
